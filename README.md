  ## 🌱 Currently building - [Organic](https://organichub.fun)
                                                                                                                                                                   
  A multi-tenant **DAO platform** where communities propose, vote, run sprints, and earn reputation. Solana-linked wallets, on-demand translation across `en` / 
  `pt-PT` / `zh-CN`, treasury-backed points + XP economy, and a launchpad for partner projects.
